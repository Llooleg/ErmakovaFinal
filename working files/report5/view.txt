[23 #19000000 @Style_2] 1. Цель исследования и исходные данные
[24 #1A000000 &a6] Цель работы — построить регрессионные модели разной сложности для временного ряда инцидентов SSH brute-force, сравнить описание известных данных с прогнозированием будущих наблюдений и определить ограничения использованных зависимостей.
[25 #1B000000 &a6] В исследовании используется 101 наблюдение с шагом 30 секунд за 3 сентября 2026 года, с 10:26:30 до 11:16:30. Период 1–60 используется только для оценки параметров, значения 61–101 — для сравнения прогнозов с фактом. Прогнозные величины не обязаны быть целыми, поскольку представляют собой математическое ожидание числа событий.

[31 #34000000 @Style_2] 2. Однофакторная регрессия и линия тренда
[32 #35000000 &a6] Линейная модель связывает число событий с номером временного интервала. Параметры рассчитываются методом наименьших квадратов по 60 обучающим точкам. Случайная составляющая ε_t — отличие фактического значения от условного среднего модели.
[33 #36000000 &a4 +i;size=13pt] yₜ = a + b·t + εₜ;     ŷₜ = 21,392655 + 0,01444846·t
[34 #37000000 &a6] Положительный коэффициент b равен приблизительно 0,0144 инцидента на один 30-секундный шаг. Линейная регрессия и тренд, построенные на одних и тех же 60 точках методом МНК, совпадают. На проверочном участке получены MAE = 2,200, RMSE = 2,895 и MAPE = 10,85 %.

[41 #3E000000 @Style_2] 3. Многофакторная регрессия 
[42 #3F000000 &a6] Для прогностической модели используются номер временного интервала и три последних известных значения числа инцидентов. Коэффициенты найдены по точкам 4–60.
[43 #40000000 &a4 +i;size=13pt] ŷₜ = 18,30184 + 0,00597·t + 0,14283·yₜ₋₁ − 0,02264·yₜ₋₂ + 0,03723·yₜ₋₃
[44 #41000000 &a6] На прежнем графике колебания на обучении сменялись почти прямой после границы 60-й точки. Это происходило потому, что на периоде 61–101 модель рекурсивно подставляла собственные прогнозы. В таком режиме колебания лаговых значений затухают, и функция приближается к плавной траектории. Данное поведение обусловлено формой расчёта, а не изменением цвета графика.
[45 #42000000 &a6] Для наглядного сопоставления дополнительно реализован прогноз на один шаг вперёд: перед каждым следующим вычислением используются только уже наблюдавшиеся три предыдущих значения. Это последовательное обновление входов даёт колеблющуюся оценку. На рисунке 6 она соединена одной непрерывной линией одного цвета — от обучающего участка до контрольного.

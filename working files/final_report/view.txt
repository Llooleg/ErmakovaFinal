[7 #622A86FE @Heading1 before=0pt] 2. Построение единой многофакторной функции генетическим алгоритмом
[8 #60E8944E @* align=both] Каждая особь в генетическом алгоритме кодирует восемь неотрицательных весов исходных функций, общий сдвиг и три дополнительных коэффициента предыдущих наблюдений. Веса нормируются до суммы единица; несущественные веса обнуляются. Качество определяется на нескольких временных разбиениях, целиком находящихся внутри первых 60 точек.
[9 #1E6B5BB4 @* &a2 +i] ŷ(t) = clip[ μ + Σ wⱼ·(fⱼ(t, …) − μ) + c + Σ γₖ·(y(t−k) − μ) ],   j = 1…8, k = 1…3
[10 #757FA2A8 @* align=both] Здесь μ — среднее значение обучающего ряда, fⱼ — исходные зависимости, c — свободное смещение, γₖ — коэффициенты лагов. Операция clip ограничивает прогноз диапазоном [0; C], причём верхний порог C определяется только по обучающим точкам. Ограничение введено для физической осмысленности числа событий; без него высокостепенные полиномы могут давать гигантские отрицательные значения.

Это план для лабораторной работы
Необходимо построить аппроксимирующую непрерывную функцию многих переменных
коридор ошибок (5%) - ограничение только коридор ошибок и данных об инцидентах в формате CSV
На вход программы для построения функции многих переменных необходимо передать ВСЕ элементарные математические функции
программы должна перебрать коэф, степени, периоды, сдвиги, программы должна найти оптимальную функцию
О совершенных экспериментах по подбору оптимальной функции необходимо записывать в REPORT.md

MAE, MSE, MAPE, RMSE, выборочная дисперсия ошибок

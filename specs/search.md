# Спецификация поиска оптимальной функции

## 1. Выбранный подход

Поиск выполняется методом символьной регрессии с генетическим программированием. ГП изменяет структуру дерева выражения; численный оптимизатор подбирает параметры конкретной структуры.

Контрольная выборка не передаётся ни одному компоненту поиска или выбора.

## 2. Начальная популяция

1. В популяцию включаются простые обязательные кандидаты: константа и линейная комбинация разрешённых переменных.
2. Остальные деревья создаются случайно в пределах минимальной и максимальной начальной глубины.
3. Используется сочетание полного и растущего создания деревьев, чтобы не начинать поиск с однотипных структур.
4. Каждый новый кандидат проходит проверку области определения.
5. Начальная популяция, seed и конфигурация генератора сохраняются.

## 3. Оптимизация параметров

### 3.1 Линейные коэффициенты

Если при фиксированных нелинейных параметрах выражение линейно по коэффициентам, применяется метод наименьших квадратов. Вырожденность матрицы проверяется; при вырождении используется регуляризованное решение либо кандидат отклоняется с указанием причины.

### 3.2 Нелинейные параметры

К нелинейным параметрам относятся степени, периоды, сдвиги и коэффициенты внутри нелинейных функций.

- Для задачи наименьших квадратов допускается метод Левенберга–Марквардта при выполнимых ограничениях метода.
- Для оптимизации с границами применяется L-BFGS-B либо другой зафиксированный ограниченный метод.
- BFGS и Левенберг–Марквардт не считаются взаимозаменяемыми названиями одного алгоритма.
- При неудовлетворительных производных, разрывах или недифференцируемых ограничениях применяется заранее выбранный безградиентный локальный метод.

Параметры оптимизируются только на соответствующем обучающем участке. Результат валидации не используется как цель оптимизатора.

### 3.3 Бюджет оптимизации

Для каждого кандидата сохраняются число вызовов целевой функции, статус сходимости и время. Структурно эквивалентные кандидаты используют общий кеш. Лимиты оптимизации задаются до запуска и одинаковы для сравниваемых структур одного этапа.

## 4. Генетические операторы

Поддерживаются:

1. **Скрещивание поддеревьев** — обмен совместимыми поддеревьями двух родителей.
2. **Точечная мутация** — замена функции или оператора с сохранением арности.
3. **Мутация поддерева** — замена ветви новым случайным деревом.
4. **Мутация параметра** — изменение константы, степени, периода или сдвига в заданных границах.
5. **Сокращение** — удаление нейтральных и избыточных ветвей без изменения области определения.
6. **Элитизм** — сохранение ограниченного числа недоминируемых кандидатов без потери разнообразия.

После каждого структурного изменения выполняются канонизация, проверка глубины, проверка области определения и повторная оптимизация затронутых параметров.

## 5. Контроль сложности

1. Максимальные глубина, число узлов и число параметров являются жёсткими ограничениями.
2. Операторы, приводящие к превышению ограничений, отклоняются или заменяются сокращённой версией.
3. Одинаковые по структуре формулы не занимают несколько мест в популяции.
4. Более сложная формула должна давать заранее заданный минимальный относительный прирост валидационного качества, иначе предпочитается более простая.

## 6. Цели отбора

### 6.1 Коридор 5 %

Сначала вычисляется соответствие кандидата критерию коридора из `evaluation.md`.

- Кандидаты, выполняющие заданный критерий, считаются допустимыми по точности коридора.
- Если таких кандидатов нет, сохраняется минимальное нарушение коридора, но результат не объявляется выполнившим ТЗ.
- Контрольная выборка не влияет на этот статус при поиске.

### 6.2 Фронт Парето

Для кандидатов, прошедших ограничение коридора, используются две цели:

1. минимизация валидационной RMSE;
2. минимизация взвешенной сложности.

Рекомендуемый механизм многокритериального отбора — NSGA-II. При его замене алгоритм и настройки фиксируются в REPORT. Обязательные MAE, MSE, MAPE и дисперсия рассчитываются и сохраняются, но не обязаны одновременно быть отдельными целями эволюции.

Если допустимых по коридору кандидатов недостаточно, нарушение коридора добавляется как третья минимизируемая цель. Это диагностический поиск, а не скрытое ослабление требования.

## 7. Временная проверка

1. Порядок наблюдений сохраняется; случайное перемешивание временного ряда запрещено.
2. Внутри обучения используются последовательные разбиения с обучающим окном, предшествующим валидационному окну.
3. Все границы параметров, правила отбора и бюджет поиска одинаковы для сравниваемых разбиений.
4. Для лаговых моделей режим обновления истории — фактические прошлые значения или рекурсивные прогнозы — фиксируется заранее и не смешивается в одной метрике.
5. Итоговые кандидаты оцениваются на каждом внутреннем разбиении; сохраняются среднее и разброс метрик.

## 8. Выбор итогового решения

1. Фронт строится только по внутренней валидации.
2. Кандидаты сортируются по сложности.
3. Точка излома определяется правилом минимального относительного прироста RMSE, заданным в конфигурации.
4. Если прирост от усложнения ниже порога, выбирается более простая формула.
5. При равенстве в пределах численного допуска выбирается меньшее число узлов, затем меньшее число параметров.
6. Выбранная формула, оптимизатор и все параметры замораживаются до открытия контрольной выборки.

Порог излома не подбирается по красивому итоговому графику или контрольным метрикам.

## 9. Условия остановки

Поиск прекращается по первому выполненному условию:

- достигнут лимит поколений;
- исчерпан лимит вычислений или времени;
- заданное число поколений нет значимого улучшения фронта;
- найдено решение, полностью удовлетворяющее заранее заданным критериям остановки.

Причина остановки обязательна в журнале.

## 10. Запись эксперимента

Для каждого запуска сохраняются:

- seed и конфигурация;
- начальный и конечный размеры популяции;
- вероятности операторов;
- бюджет и фактическое время;
- число отклонённых кандидатов по причинам;
- лучшие формулы каждого уровня сложности;
- валидационный фронт Парето;
- выбранная формула и правило выбора;
- контрольные метрики после заморозки;
- вывод о выполнении или невыполнении коридора 5 %.
